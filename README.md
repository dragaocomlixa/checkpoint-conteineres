# Controle de Contêineres

Projeto acadêmico de Programação 2 para aplicar lógica procedural, matrizes e interface gráfica em Python.

## Proposta

O sistema representa um pátio logístico por uma matriz de 5 linhas e 6 colunas, totalizando 30 posições. O valor 0 indica posição livre e o valor 1 indica posição ocupada.

Ao informar uma identificação e clicar em uma posição livre, o programa registra a chegada. Ao clicar em uma posição ocupada, solicita confirmação e registra a saída. Os totais são atualizados em tempo real e um resumo é exibido antes de encerrar.

## Requisitos atendidos

- Python com `tkinter` e `tkinter.ttk`;
- estilo nativo com `ttk.Style`;
- paradigma estritamente procedural, sem classes próprias;
- matriz 5 x 6 como fonte de verdade;
- validações por `messagebox`;
- layout com `grid` e `pack`;
- comentários pedagógicos para estruturas de controle e funções de alto nível.

## Como executar

Não há bibliotecas externas:

```powershell
python main.py
```
