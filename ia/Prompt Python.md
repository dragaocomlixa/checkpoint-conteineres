# Prompt Python

Atue como um desenvolvedor Python sênior especializado no ensino acadêmico de lógica estruturada e procedural.

Crie um programa completo usando tkinter e tkinter.ttk, com estilo nativo por ttk.Style.

## Regras obrigatórias

1. Use apenas funções, variáveis e estruturas de controle; não crie classes próprias.
2. Ao usar funções nativas de alto nível, operadores de busca, fatiamento ou métodos utilitários, inclua comentários pedagógicos explicando seu papel e o algoritmo tradicional relacionado.
3. Evidencie sequência, seleção e repetição.

## Contexto

- Pátio em matriz 5 x 6, com 30 posições.
- 0 representa posição livre e 1 representa posição ocupada.
- Clique em posição livre registra chegada.
- Clique em posição ocupada confirma saída.
- Atualize a contagem e mostre resumo ao encerrar.
- Valide entradas e fluxos com messagebox; organize a interface com grid ou pack.

## Entrega

Mantenha o código legível, comentado para fins didáticos e sem dados pessoais, tokens ou chaves de API.
