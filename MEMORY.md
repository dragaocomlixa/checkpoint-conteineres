# Memória de trabalho

## Contexto

Projeto acadêmico de Programação 2 sobre a organização procedural de um pátio de contêineres.

## Estado conhecido

- A matriz ocupacao possui 5 linhas e 6 colunas.
- O valor 0 representa posição livre; o valor 1 representa posição ocupada.
- A matriz identificacoes acompanha os códigos armazenados.
- A interface utiliza tkinter, tkinter.ttk, grid, pack e messagebox.
- O código principal não cria classes próprias.
